One job title, 41 characters: a senior lighthouse keeper — inland, with no
sea in sight. A real-sounding job with one gloriously impossible twist.

`main.py` (pure Python standard library, `os` only) writes exactly one line
— the title — to `/output/entry.txt`.

## Run it

```sh
python3 main.py
```

Writes the title to `/output/entry.txt` (`MAKEFUN_OUTPUT_DIR` overrides the
output directory). Deterministic: the same title, byte for byte, on every run.
